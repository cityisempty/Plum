# 头像图片说明

## 文件夹结构

```
public/avatars/
├── male/          # 男性头像
│   ├── 15.png    # 15-19岁
│   ├── 20.png    # 20-24岁
│   ├── 25.png    # 25-29岁
│   ├── 30.png    # 30-34岁
│   ├── 35.png    # 35-39岁
│   ├── 40.png    # 40-44岁
│   ├── 45.png    # 45-49岁
│   ├── 50.png    # 50-54岁
│   ├── 55.png    # 55-59岁
│   └── 60.png    # 60岁及以上
└── female/        # 女性头像
    ├── 15.png    # 15-19岁
    ├── 20.png    # 20-24岁
    ├── 25.png    # 25-29岁
    ├── 30.png    # 30-34岁
    ├── 35.png    # 35-39岁
    ├── 40.png    # 40-44岁
    ├── 45.png    # 45-49岁
    ├── 50.png    # 50-54岁
    ├── 55.png    # 55-59岁
    └── 60.png    # 60岁及以上
```

## 年龄映射规则

- 15-19岁 → 15.png
- 20-24岁 → 20.png
- 25-29岁 → 25.png
- 30-34岁 → 30.png
- 35-39岁 → 35.png
- 40-44岁 → 40.png
- 45-49岁 → 45.png
- 50-54岁 → 50.png
- 55-59岁 → 55.png
- **60岁及以上 → 60.png (固定,不再变化)**

## 图片要求

- **格式**: PNG (支持透明背景)
- **尺寸建议**: 200x250 像素 (宽x高)
- **命名**: 严格按照年龄段命名 (15.png, 20.png, 25.png, ..., 60.png)
- **内容**: 符合对应年龄段特征的头像

## 使用说明

1. 将准备好的图片按照上述命名规则放入对应文件夹
2. 男性头像放入 `public/avatars/male/`
3. 女性头像放入 `public/avatars/female/`
4. 系统会根据用户选择的年龄自动加载对应的图片
